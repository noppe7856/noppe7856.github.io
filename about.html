🌱 このサイト・運営者について

のっぺのアプリ広場（Noppe's App & Game Lab）は、日々の勉強や活動の中で「こんなアプリがあったら楽しいな・助かるな」と思ったアイデアを形にして、誰でも無料で使えるように公開している個人開発のWebアプリ＆ミニゲームポータルです。

安心してご利用いただくための4つの方針

🔒 会員登録・個人情報収集なし メールアドレスやパスワード登録を求めることはありません。開いたその瞬間からすぐ遊べます。
💾 学習データは端末内のみで管理 漢字の復習記録や設定などは、お使いのブラウザのローカルストレージ（localStorage）にのみ保存されます。
💻 オープンソースで透明性を確保 すべてのアプリおよび本サイトのソースコードを GitHub で公開しており、不審な通信や処理がないことを確認できます。
🛡️ 安全な通信と配信基盤 全ページを GitHub Pages の常時 HTTPS 暗号化通信で配信しています。意図しない課金誘導や悪質なポップアップは一切行いません。
