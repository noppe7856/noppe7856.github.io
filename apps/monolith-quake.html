🌍 MONOLITH

ホワイトベース・完全モノクロームデザインの 3D地球儀リアルタイム地震モニター & Lo-Fi チルミュージックプレイヤー です。 作業用BGMを流しながら世界中の地震活動を静かに眺められる、ミニマルで美しいWebアプリです。

▶ 今すぐMONOLITHを開く 💻 GitHubでソースを見る

主な機能

🌐 磁器調マットホワイト3D地球儀 カスタムGLSLシェーダーで描かれた美しいモノクローム地球儀。ドラッグやタッチで滑らかに回転・ズームでき、自動回転ON/OFFにも対応。
✨ 震源インクパーティクル＆3重リップル 地震が発生すると震源へ極小の黒パーティクルが螺旋状に集束し、インクハローと3重の3Dリップルリングが広がります。
📡 LIVE監視 ＆ 30日間タイムライン再生 USGSのリアルタイム地震データを60秒ごとに定期監視する LIVE モードと、過去30日間を速度切替・マグニチュードフィルタで振り返れる HISTORY 30D モードを搭載。
🎧 Web Audio API Lo-Fiチル自動生成 外部音声ファイル不要で、3種のコード進行・スウィングドラム・レコードノイズ・波形表示をブラウザ内でリアルタイム合成します。

こんな方におすすめ

  • 勉強やデスクワーク中に、落ち着いたモノクローム映像と Lo-Fi BGM を流しておきたい方
  • 世界中の地震の起き方やプレート境界の活動を3D地球儀で直感的に観察したい方
  • Three.js・GLSLシェーダー・Web Audio API・SysML v2（MBSE）の実装事例に興味がある開発者の方

動作環境・透明性

WebGL および Web Audio API に対応した最新ブラウザ（Chrome / Edge / Safari 等）で動作します。会員登録不要・無料で、全ソースコードおよび SysML v2 モデル・自動検証テストを GitHub 上で公開しています。
