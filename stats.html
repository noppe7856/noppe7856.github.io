📊 アクセス状況・客観的計測ダッシュボード

管理者向けに、ポータルサイトおよび全アプリ（kanji-flashcard / tebata-trainer 等）の客観的アクセス計測ステータスと、各公式分析ツールへのショートカットをまとめています。

1. 客観的アクセス計測サービスの連携状況

本サイトと各アプリは共通モジュール js/analytics.js を読み込んでいます。 js/site-config.js に ID を1箇所設定するだけで、ポータル＋全アプリのPV・訪問者数・流入元・アプリ起動回数を一括計測できます。

2. 公開中サイト・リポジトリ一覧（GitHub ライブ情報）

サイト / アプリ 公開URL GitHub Star 最終更新 リポジトリ Traffic

3. 最短3分で客観的アクセス計測を始める手順

初めての方には、Cookie不要・無料・登録後すぐに見やすいグラフが出る GoatCounter と、詳細な検索流入やクリック分析ができる Google Analytics 4 (GA4) ＋ Search Console の併用がおすすめです。

  1. GoatCounter（おすすめ・最速）： goatcounter.com で無料アカウントを作成し、コード名（例：noppe7856）を取得します。
  2. Google Analytics 4 (GA4)： analytics.google.com でウェブストリーム（URL: https://noppe7856.github.io）を作成し、測定ID（G-XXXXXXXXXX）を取得します。
  3. 設定ファイル1箇所を更新して push： js/site-config.js の analytics セクションを以下のように書き換えるだけで、ポータル全ページと各アプリのアクセス数・起動イベント（play_app / app_open / share_click / support_click）が自動計測されます。 
analytics: {
  ga4: {
    enabled: true,
    measurementId: "G-XXXXXXXXXX"
  },
  goatcounter: {
    enabled: true,
    code: "noppe7856",
    publicDashboard: false
  },
  cloudflare: {
    enabled: false,
    beaconToken: ""
  },
  searchConsoleVerification: "Google Search Consoleの確認コード"
}

4. 計測イベントの動作確認方法

任意のページに ?debug_analytics=1 を付けて開き、ブラウザの開発者ツール（Console）を見ると、送信されるページビューおよびクリックイベント（play_app, app_open, share_click, support_click）をリアルタイムで確認できます。
